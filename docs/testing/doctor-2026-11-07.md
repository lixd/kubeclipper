## 原因与修改

口令登录上下文保存 KC API Token。旧 doctor 从该上下文读取 etcd CA 和客户端证书，
在建立 etcd 连接前返回 `certificate authority is unavailable`。

新 doctor 通过现有 SSH 配置，在健康的 Server 主机执行部署物料自带的
`/usr/local/bin/etcdctl`。它使用服务端的 CA 和 `kube-etcd-healthcheck-client` 专用
证书，依次执行 `endpoint health --cluster` 和 `endpoint status --cluster`，
核对健康结果并提取 leader。证书与私钥由远端 etcdctl 直接读取。

执行前检查工具可执行性和三个证书文件的可读性，命令保留超时。
前置条件缺失或 SSH 无法执行时报告 Unknown，健康检查失败报告 Unhealthy，
健康通过但成员状态缺失或异常时报告 Degraded。
