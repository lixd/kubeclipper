### 附带观察（非 4-07 阻塞，记录跟进）

内置聚合角色（`cluster-manager` 等）在**授权期不展开** `kubeclipper.io/aggregation-roles`：
`pkg/authorization/rbac/rbac.go:136 getRoleReferenceRules` 仅取 `globalRole.Rules`，而内置角色
`rules` 只有基础规则（聚合注解仅在角色创建/更新的 API 路径被展开进 `rules`）。实测非 admin
用户（`cluster-manager`）访问备份空间 API 得 **403**，UI 报"获取备份空间失败。/ Forbidden"。
本轮改用平台管理员用户完成 4-07 验证。属 RBAC 权限模型问题，7 章覆盖范围，不影响 4-07 结论。
