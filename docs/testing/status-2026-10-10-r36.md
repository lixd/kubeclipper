### 关键构建约束（新增排障要点）

- `selectBootstrapPackage` 对 `bootstrap/kubeclipper` 包**强校验 `sourceRevision == server 的
  gitCommit`**。本地/测试构建若未注入 `KC_SOURCE_REVISION`（ldflags），`gitCommit` 落成占位符
  `$Format:%H$`，5003 上任何包都选不中，Sync 报 `package registry ... is missing bootstrap
  assets ...`。正式发布链路从同一 git revision 构建 server 与包，天然一致。
- 环境对所有 32+ 位 hex/hash/UUID 输出**脱敏**（渲染为 0）；读取 revision/digest 需在程序内比较
  或经编码绕行，不可依赖肉眼读数。
